# site — 모바일 편성 허브 컨셉 화면 (v3.5)

정적 파일만으로 동작하는 화면입니다. 외부 라이브러리와 외부 요청이 없고, 브라우저에서 `index.html`을 바로 열어도 동작합니다.

- 공개 주소: https://analytics-corp.github.io/curation-hub-view/ (정본 `main`의 이 폴더가 바뀌면 워크플로 `sync-site`가 공개 저장소 `analytics-corp/curation-hub-view`의 `main`으로 복사)
- 데이터: 시드 고정 가상 데이터(`data.js`). 구좌명·팀명·브랜드명·코드는 실제 명칭, 실적·트래픽 수치는 모두 가상.
- 화면: 편성 요약 / 구좌별 현황 / 영업팀별 현황 / 전시 행사별 현황 / 편성 데일리 리포트 / 기준 안내

## 파일

| 파일 | 역할 |
|---|---|
| `index.html` | 화면 뼈대, 조회 조건, 기준 안내 본문 (변경 이력은 이 문서 맨 아래) |
| `styles.css` | 기본 스타일. 색 토큰은 `:root`에 모음(라이트·다크) |
| `styles-slot.css` | 구좌별 현황 전용. Hmall 광고 구좌 안내 페이지 양식(빨간 점선 구좌·이름표, 화면 그룹·구좌 칩, 결과 카드·사실 표) |
| `data.js` | 가상 데이터 생성 + 구좌 위치 메타(`LAYOUT`: 화면, 캡처 파일, 캡처 안 구좌 영역 `box`, 설명 / `SCREENS`) |
| `app-core.js` | 상태, 조회 기간, 집계, 링크 상태, 조회 조건 UI, 테마 |
| `app-charts.js` | SVG 차트(세로 막대·스파크라인·덤벨), 가로 막대, BEST 목록, 화면별 구좌 나열 |
| `app-home.js` | 편성 요약 |
| `app-slot.js` | 구좌별 현황(앱 화면 캡처 + 화면·구좌 선택 + 결과 카드, 표, 가중치, 주요 탭 PV) |
| `app-team.js` | 영업팀별 현황, 전시 행사별 현황 |
| `app-report.js` | 편성 데일리 리포트, 기준 안내, 공통 동작, 초기화 |
| `img/` | 구좌 캡처 PNG 16장(월간 리포트 1번 시트 셀 메모 이미지, 약 300×640px, 2026-10-26 Master 재업로드 고화질본. 이벤트아이콘 1·2번줄은 한 장 공용). 저장소 루트의 원본 PNG 18장을 구좌 코드 이름으로 복사한 것 |
| `tests/harness.js` | Node 검사 하네스 |
| `tests/browser/` | 실제 브라우저(Firefox headless) 점검 스크립트. `interact.mjs` 클릭·동작 74개, `layout.mjs` 줄바꿈·넘침·말줄임 측정(화면 6개 × 폭 8단계), `cdp.mjs`(Chrome)·`bidi.mjs`(Firefox) 연결 도구 |

## 검사

```
cd site && node tests/harness.js
```

집계 불변식, 화면×기간×조건 스모크, 링크 상태 왕복, NaN/undefined 검출, 파일 크기 상한(파일당 20KB), 구좌 칩·앱 화면 캡처·결과·TOP 5·더 보기 동작, 상태 문구 없음, 왼쪽 메뉴 숨기기/보기를 검사합니다.

실제 브라우저 점검(Node 22 필요, 외부 패키지 없음). Master는 Chrome을 쓰므로 Chrome 점검을 기준으로 합니다(Firefox는 `BROWSER` 없이 실행):

```
cd site && BROWSER=chrome node tests/browser/interact.mjs .
cd site && BROWSER=chrome node tests/browser/layout.mjs . /tmp/hub-layout
cd site && BROWSER=chrome WIDE=1 node tests/browser/layout.mjs . /tmp/hub-layout-wide
```

Chrome 실행 파일이 PATH에 없으면 `CHROME=경로` 로 지정합니다. `WIDE=1` 은 글자 간격을 넓혀 Windows 맑은 고딕처럼 넓은 글꼴을 흉내 냅니다.

`interact.mjs` 는 모든 버튼·조회 조건·화면 이동·메뉴 숨기기·링크 복사·좁은 화면 동작과 콘솔 오류를, `layout.mjs` 는 한글 단어 중간 줄바꿈, 마지막 줄에 한 단어만 남은 줄, 짧은 괄호 묶음 안 줄바꿈, 가로 넘침, 말줄임(…) 잘림 수를 화면별·폭별(1920·1536·1440·1366·1280·1024·860·390px)로 셉니다. 둘 다 0건이 기준입니다.

## 갱신 규칙

- 코드 파일은 파일당 20KB 이하를 유지합니다(세션이 API로 직접 올릴 수 있는 크기). 넘으면 파일을 나눕니다.
- 이미지 등 바이너리는 git 푸시로만 정본에 반영합니다(API 전송은 바이트가 바뀜).
- 공개 저장소 반영은 정본 `main` 병합 시 워크플로가 자동으로 합니다. 세션은 병합 후 공개 저장소 파일 sha가 정본과 같은지 확인합니다.
