# site — 모바일 편성 허브 컨셉 화면 (v3.1)

정적 파일만으로 동작하는 화면입니다. 외부 라이브러리와 외부 요청이 없고, 브라우저에서 `index.html`을 바로 열어도 동작합니다.

- 공개 주소: https://analytics-corp.github.io/curation-hub-view/ (정본 `main`의 이 폴더가 바뀌면 워크플로 `sync-site`가 공개 저장소 `analytics-corp/curation-hub-view`의 `main`으로 복사)
- 데이터: 시드 고정 가상 데이터(`data.js`). 구좌명·팀명·브랜드명·코드는 실제 명칭, 실적·트래픽 수치는 모두 가상.
- 화면: 편성 요약 / 구좌별 현황 / 영업팀별 현황 / 전시 행사별 현황 / 편성 데일리 리포트 / 기준 안내

## 파일

| 파일 | 역할 |
|---|---|
| `index.html` | 화면 뼈대, 조회 조건, 기준 안내 본문, 변경 이력(하단 주석) |
| `styles.css` | 기본 스타일. 색 토큰은 `:root`에 모음(라이트·다크) |
| `styles-slot.css` | 구좌별 현황 전용(왼쪽 앱 화면 캡처와 구좌 영역, 화면·구좌 선택, 결과) |
| `data.js` | 가상 데이터 생성 + 구좌 위치 메타(`LAYOUT`: 화면, 캡처 파일, 캡처 안 구좌 영역 `box`, 설명 / `SCREENS`) |
| `app-core.js` | 상태, 조회 기간, 집계, 링크 상태, 조회 조건 UI, 테마 |
| `app-charts.js` | SVG 차트(세로 막대·스파크라인·덤벨), 가로 막대, BEST 목록, 화면별 구좌 나열 |
| `app-home.js` | 편성 요약 |
| `app-slot.js` | 구좌별 현황(앱 화면 캡처 + 화면·구좌 선택 + 결과, 표, 가중치, 주요 탭 PV) |
| `app-team.js` | 영업팀별 현황, 전시 행사별 현황 |
| `app-report.js` | 편성 데일리 리포트, 기준 안내, 공통 동작, 초기화 |
| `img/` | 구좌 캡처 18장(월간 리포트 1번 시트 셀 메모 이미지, 약 300×640px JPEG) |
| `tests/harness.js` | Node 검사 하네스 |

## 검사

```
cd site && node tests/harness.js
```

집계 불변식, 화면×기간×조건 스모크, 링크 상태 왕복, NaN/undefined 검출, 파일 크기 상한(파일당 20KB), 구좌 칩·앱 화면 캡처·결과·TOP 5·더 보기 동작, 상태 문구 없음을 검사합니다.

## 갱신 규칙

- 코드 파일은 파일당 20KB 이하를 유지합니다(세션이 API로 직접 올릴 수 있는 크기). 넘으면 파일을 나눕니다.
- 이미지 등 바이너리는 git 푸시로만 정본에 반영합니다(API 전송은 바이트가 바뀜).
- 공개 저장소 반영은 정본 `main` 병합 시 워크플로가 자동으로 합니다. 세션은 병합 후 공개 저장소 파일 sha가 정본과 같은지 확인합니다.
